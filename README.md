# AutoBook 自动记账

本项目是一个本地优先的 Android 自动记账 App，面向红米 80 Pro / Android 16 侧载安装场景。

## 功能

- 监听微信、支付宝、云闪付、京东支付通知并自动解析账单。
- 可选无障碍服务，用于辅助识别支付成功页并尝试自动截图。
- 手动导入消费截图，使用本地 ML Kit OCR 识别金额、商户和分类。
- Room 本地数据库保存账单、分类、规则和截图索引。
- 截图和 OCR 原文保存在 App 私有目录，并通过 Android Keystore AES-GCM 加密。
- Compose 精致工具风 UI：账本、统计、待确认、设置。

## 构建

需要安装 JDK 17、Android SDK，并在 `local.properties` 或环境变量中配置 SDK 路径。

```powershell
gradle :app:assembleDebug
```

如果希望使用 Gradle Wrapper，可在有 Gradle 的环境中执行：

```powershell
gradle wrapper --gradle-version 8.10.2
```

## 手机上启用

1. 安装 debug APK 后打开 App。
2. 在“设置”页进入“通知监听”，允许“自动记账通知监听”。
3. 可选进入“无障碍辅助”，开启“自动记账辅助服务”，用于支付成功页自动截图尝试。
4. 在红米/HyperOS 设置中允许自启动、后台运行，并关闭过度省电。
5. 在首页点“导入截图”可以手动选择支付截图，识别后到“待确认”页核对入账。

## 已实现的第一版能力

- 本地 Room 账本数据库。
- 支付通知解析与去重。
- 手动截图导入、本地 OCR、加密保存截图和 OCR 原文。
- 无障碍服务自动截图骨架，失败时静默降级。
- 手动记账、待确认补录、分类统计、CSV 导出。
- 精致工具风 Compose UI。

## 重要限制

- Android 不允许普通 App 无条件读取第三方 App 交易数据，本项目以通知监听为主。
- 自动截图依赖无障碍能力和系统/支付 App 策略，遇到安全窗口会失败并自动降级。
- 项目不接入后端，不上传通知、截图或账单数据。
